# 0004 — ruff instead of black + isort + flake8

**Status:** accepted

## Context

MeshDB lints Python with black, isort, and flake8 — three tools, three
configurations, three ways for a contributor's environment to disagree with CI.

[ruff](https://docs.astral.sh/ruff/) implements the rules of all three, plus
pyupgrade and flake8-bugbear, in a single binary.

## Decision

Use ruff for both linting and formatting. Configuration lives in
`backend/pyproject.toml` alongside everything else.

## Consequences

- One tool to install, one configuration to read, one command to run.
- Fewer steps between a new contributor and a passing build — the primary reason
  for the change.
- ruff's formatter is black-compatible but not byte-identical, so formatting
  differs slightly from MeshDB's. This affects nothing but diffs.
- Should ruff ever lack a rule we need, flake8 plugins are not available to us.
